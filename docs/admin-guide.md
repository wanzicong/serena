## 简介

Serena 管理后台是一个基于 Web 的可视化管理界面，用于管理 Serena AI 编程代理的各项功能。通过管理后台，您可以：

- 管理已注册的项目
- 查看和控制可用工具
- 查看和编辑系统配置
- 实时监控系统状态和日志

### 技术架构

管理后台采用以下技术栈：

- **后端**: Flask 3.x Web 框架
- **前端**: Jinja2 模板 + 原生 JavaScript
- **样式**: 自定义 CSS（响应式设计）
- **数据持久化**: YAML 配置文件
- **输入验证**: Pydantic

## 快速开始

### 启动管理后台

在项目根目录下运行：

```bash
uv run serena-mcp-server --project .
```

默认情况下，管理后台将在以下地址启动：

```
http://localhost:8000/admin
```

### 首次访问

1. 打开浏览器，访问 `http://localhost:8000/admin`
2. 您将看到项目管理页面（默认入口）
3. 使用顶部导航栏在不同功能模块间切换

### 停止服务

在终端中按 `Ctrl+C` 停止服务器。

## 功能概览

管理后台包含以下主要功能模块：

| 模块 | 路由 | 功能描述 |
|------|------|----------|
| 项目管理 | `/admin/projects` | 查看和管理注册的项目 |
| 工具管理 | `/admin/tools` | 查看和控制可用工具 |
| 工具统计 | `/admin/tools/stats` | 查看工具使用统计信息 |
| 配置管理 | `/admin/config` | 查看系统配置概览 |
| 系统监控 | `/admin/monitoring` | 监控系统状态和任务 |
| LSP 监控 | `/admin/monitoring/lsp` | 监控语言服务器状态 |
| 日志查看 | `/admin/monitoring/logs` | 查看系统日志 |

## 项目管理

### 查看项目列表

访问 `/admin/projects` 可以查看所有已注册的项目。

项目列表显示以下信息：

- **项目名称**: 项目的唯一标识符
- **路径**: 项目在文件系统中的绝对路径
- **语言**: 项目支持的语言列表（如 Python、TypeScript 等）
- **状态**:
  - 绿色"活跃"标签表示当前激活的项目
  - 灰色"未激活"标签表示未激活的项目
  - 灰色"只读"标签表示只读模式的项目
- **操作**: 可用的操作按钮

### 激活项目

1. 在项目列表中找到要激活的项目
2. 点击"激活"按钮
3. 系统将切换到该项目，并显示成功提示

**注意**: 一次只能激活一个项目。激活新项目会自动取消当前项目的激活状态。

### 创建新项目

1. 点击页面底部的"添加新项目"按钮
2. 在创建页面输入项目的本地路径
3. 系统将自动扫描项目并识别：
   - 项目名称（从路径推断）
   - 使用的语言
   - 项目结构
4. 点击"创建"完成项目注册

**支持的语言**: Python、Go、Java、Rust、TypeScript、Vue、PHP、Perl、PowerShell、C#、Elixir、Terraform、Clojure、Swift、Bash、Ruby 等。

### 编辑项目

1. 在项目列表中点击"编辑"按钮
2. 在编辑页面可以修改：
   - 项目名称
   - 支持的语言
   - 只读模式设置
3. 点击"保存"应用更改

### 删除项目

1. 在项目列表中点击"删除"按钮
2. 确认删除操作
3. 项目将从配置中移除

**警告**: 删除项目不会删除项目文件，只是从 Serena 配置中移除该项目的注册信息。

## 工具管理

### 查看工具列表

访问 `/admin/tools` 可以查看所有可用的工具。

工具列表显示以下信息：

- **工具名称**: 工具的标识符
- **状态**: 工具是否处于活跃状态
- **调用次数**: 该工具被调用的总次数
- **操作**: 启用或禁用工具

页面顶部还显示统计摘要：
- 总工具数
- 活跃工具数
- 总调用次数

### 启用/禁用工具

1. 在工具列表中找到要操作的工具
2. 点击"启用"或"禁用"按钮
3. 确认操作（禁用时需要确认）
4. 系统将更新工具状态

**注意**: 工具切换功能会修改项目配置文件。如果项目配置为只读，该功能将不可用。

### 查看工具统计

访问 `/admin/tools/stats` 查看详细的使用统计信息：

- 每个工具的调用次数
- 工具使用的频率分布
- 最常用的工具排行

## 配置管理

### 查看配置概览

访问 `/admin/config` 可以查看系统的配置概览，包括：

- **活跃项目**: 当前激活的项目
- **可用上下文**: 配置的上下文（如 desktop-app、agent、ide-assistant）
- **活跃模式**: 当前激活的模式（如 planning、editing、interactive）
- **可用工具**: 工具列表及其状态

配置以层次结构显示，便于理解各个配置项之间的关系。

## 系统监控

### 监控概览

访问 `/admin/monitoring` 查看系统整体状态。

#### 状态卡片

页面顶部显示三个状态卡片：

1. **LSP 服务器**: 当前活跃的语言服务器数量
2. **活跃任务**: 正在执行或队列中的任务数量
3. **活跃项目**: 当前激活的项目名称

#### LSP 语言服务器

显示当前运行的语言服务器列表，包括：

- 语言名称
- 语言服务器类型
- 运行状态

#### 当前任务

显示当前正在执行或队列中的任务：

- 任务名称
- 状态（运行中、队列中、已完成）
- 是否已记录日志

**自动刷新**: 监控页面每 5 秒自动刷新一次。

### LSP 服务器详情

访问 `/admin/monitoring/lsp` 查看语言服务器的详细状态：

- 每个语言服务器的进程信息
- 内存使用情况
- 运行时长
- 缓存状态
- 支持的语言特性

### 日志查看

访问 `/admin/monitoring/logs` 查看系统日志。

#### 日志功能

- **实时日志**: 显示最新的系统日志条目
- **日志级别**: INFO、WARNING、ERROR 等
- **时间戳**: 每条日志的时间信息
- **来源**: 日志来源（如 LSP、Agent、Tool）

#### 日志控制

- 调整显示的日志数量（默认 100 条）
- 使用"刷新"按钮获取最新日志
- 日志按时间倒序显示（最新的在前）

## 常见问题

### Q: 如何更改管理后台的端口？

A: 修改启动命令或配置文件中的端口设置。具体方法请参考 Serena 配置文档。

### Q: 管理后台支持多用户吗？

A: 当前版本不支持多用户认证。管理后台设计为本地单用户使用。

### Q: 为什么某些功能显示"尚未实现"？

A: 管理后台仍在持续开发中。一些高级功能（如 WebSocket 实时日志、高级搜索等）将在未来版本中添加。

### Q: 如何备份我的配置？

A: Serena 配置存储在 `~/.serena/serena_config.yml` 文件中。您可以定期复制此文件进行备份。

### Q: 删除项目会影响项目文件吗？

A: 不会。删除项目只是从 Serena 配置中移除项目注册信息，不会删除或修改项目文件。

### Q: 工具切换不生效怎么办？

A: 检查以下几点：

1. 确认项目不是只读模式
2. 检查项目配置文件是否可写
3. 查看浏览器控制台是否有错误信息
4. 重新激活项目以应用更改

### Q: 监控页面自动刷新可以关闭吗？

A: 当前版本不支持关闭自动刷新。您可以通过修改浏览器开发者工具来阻止自动重定向，或等待未来版本添加此功能。

### Q: 如何查看更多日志？

A: 在日志页面调整 URL 中的 `limit` 参数，例如 `/admin/monitoring/logs?limit=500` 显示最近 500 条日志。

关于 LSP

什么是语言服务器协议 (LSP)?

语言服务器协议 (Language Server Protocol) 是一种开放协议， 用于在代码编辑器和语言服务器之间传输功能特性，如自动完成、 跳转到定义、查找引用等。

Serena 中的 LSP 支持

Serena 使用 SolidLSP 库支持 {{ lsp_status.supported_languages|length }} 种编程语言。 当激活项目时，系统会自动检测项目语言并启动相应的语言服务器。
